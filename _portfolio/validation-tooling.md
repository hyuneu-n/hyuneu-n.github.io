I build small tools around the model so that experiments can be inspected and repeated outside a notebook. The work includes C#/.NET desktop applications, WPF interfaces, ONNX model execution, visual overlays, and parameterized validation flows.

The goal is not to hide the model behind a demo. It is to make inputs, outputs, runtime behavior, and failure cases visible to the person integrating the system.
